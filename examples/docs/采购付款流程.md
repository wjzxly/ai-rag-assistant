# 采购申请与付款流程

> 示例语料，公司名称与条款均为虚构。

## 一、采购申请

### 1.1 发起

需求部门在采购系统创建《请购单》，须填写物料编码、规格、数量、需求日期、
预算科目与预估单价。**未填写物料编码的请购单一律退回**，无编码的临时采购需先由
物料主数据管理员建档。

### 1.2 审批权限

| 金额区间 | 审批人 |
| --- | --- |
| 5000 元以下 | 部门负责人 |
| 5000–50000 元 | 部门负责人 + 采购经理 |
| 50000–200000 元 | 追加财务经理 |
| 200000 元以上 | 追加总经理 |

同一需求拆分为多张请购单规避审批的，一经查实按违规处理，审批权限上调一级重新审批。

### 1.3 询比价

单笔金额超过 30000 元的采购，须取得至少 3 家供应商报价，附比价表。
独家供货或客户指定品牌的，需提供书面说明并经采购总监批准。

## 二、订单与到货

### 2.1 下单

采购员依据审批通过的请购单在系统生成采购订单（PO），
**PO 编号规则为 PO-年份-四位流水号**，例如 PO-2026-0912。
无 PO 的采购不予付款，紧急采购需在 3 个工作日内补录。

### 2.2 到货验收

仓库收货时核对 PO 号、数量与包装完整性，24 小时内完成系统入库。
质量部在 3 个工作日内完成来料检验，不合格品挂"待处理"状态，不得投入使用。

## 三、对账与发票

### 3.1 对账

每月 5 日前，采购员与供应商完成上月对账，输出《对账单》并由双方盖章确认。
对账差异超过 1% 的，暂缓付款直至查清。

### 3.2 发票要求

供应商须开具增值税专用发票，税率与合同约定一致。
发票信息必须与 PO、入库单、对账单"三单一致"，任一项不符即退回重开。

发票抬头：云杉精密制造有限公司
纳税人识别号：91441300XXXXXXXXXX（示例）

## 四、付款

### 4.1 付款条件

付款前提为"三单匹配"：采购订单、入库单、发票齐全且金额一致。
预付款需在合同中明确约定比例，原则上不超过合同总额的 30%。

### 4.2 付款周期

财务每周二、周四两批次集中付款。
资料齐全的付款申请，自提交起 **10 个工作日内**完成支付。

### 4.3 异常处理

- 发票认证失败：退回供应商重开，不计入付款周期；
- 供应商账户变更：须提供加盖公章的变更函并电话回拨确认，**严禁仅凭邮件或微信变更收款账户**；
- 超期未付：供应商可提出书面催款，财务在 5 个工作日内答复。

## 五、档案管理

采购合同、PO、对账单、发票复印件保存期限为 10 年。
电子档案统一存放在采购系统，纸质原件由财务部归档。
