# 发票合规与税务处理指引

> 示例语料，公司名称与条款均为虚构，不构成税务意见。

## 一、可报销发票类型

### 1.1 增值税专用发票

适用于可抵扣进项税的采购与费用支出。必须同时满足：

- 购买方名称、纳税人识别号与我司登记信息完全一致；
- 货物或应税劳务名称与实际业务相符，不得笼统开具"办公用品"；
- 发票联与抵扣联齐全，电子专票需提供 OFD 或 PDF 原件。

### 1.2 增值税普通发票

用于不可抵扣项目，如员工福利、餐饮、差旅住宿（小规模纳税人开具）。
普通发票同样要求抬头与税号正确，否则不得税前扣除。

### 1.3 不可报销凭证

- 收据、白条、手写单据；
- 抬头为个人或第三方公司的发票；
- 发票内容为"礼品""购物卡""预付卡"的；
- 已作废或红冲的发票（需附红字信息表说明）。

## 二、常见风险点

### 2.1 三流不一致

合同流、资金流、发票流必须指向同一交易对手。
由 A 公司签约、B 公司开票、C 公司收款的，属于典型三流不一致，一律不得付款。

### 2.2 发票异常状态

财务在认证前须在税务系统核验发票状态。出现以下情形立即冻结报销：

| 状态 | 处理方式 |
| --- | --- |
| 作废 | 退回重开 |
| 红冲 | 索取红字发票及说明 |
| 失控 | 立即上报财务负责人，暂停与该供应商合作 |
| 异常凭证 | 不得抵扣，已抵扣的作进项转出 |

### 2.3 时间性要求

发票开具日期与报销日期原则上不超过 90 天；跨年度发票须在次年 1 月 31 日前完成报销，
逾期需总经理特批。增值税专用发票的认证抵扣期限按现行税法执行，财务需在收票当月完成认证。

## 三、电子发票管理

### 3.1 查重

电子发票可重复打印，必须查重。报销系统在提交时自动比对发票代码与号码，
重复提交的将被拦截。手工报销的，由财务在台账中登记。

### 3.2 归档

电子发票原件（PDF/OFD）与报销单一起归档，不得只存截图。
归档文件命名规则：`发票号_供应商简称_金额.pdf`。

## 四、特殊业务

### 4.1 差旅住宿

住宿发票须为增值税发票，抬头公司全称。OTA 平台代订的，需索取平台开具的发票，
不得使用酒店前台开具给个人的发票。

### 4.2 会议与培训

会议费发票需附会议通知、签到表、议程；培训费需附培训协议与课程清单。
缺少附件的，按业务招待费处理，税前扣除限额不同。

### 4.3 进口业务

进口增值税与关税以海关缴款书为凭证，需在开具之日起 360 天内申报抵扣。
报关单、缴款书、合同三者信息须一致。
